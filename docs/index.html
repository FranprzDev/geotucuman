Qué hay atrás

MCPTypeScriptWFSAPI GeorefReproyección Gauss-Krüger propiaCatálogo con snapshot

Un servidor MCP por stdio en TypeScript estricto consulta servicios WFS oficiales y la API Georef. El catálogo se genera desde los GetCapabilities en vivo y preserva un snapshot si un endpoint cae; el bbox se consulta en EPSG:4326 y se reproyecta al CRS nativo de cada capa con una reproyección Gauss-Krüger/TM propia. GeoTucumán descubre y cita la fuente: no arma el mapa ni el análisis por vos.

Una capa muestra lo que contiene: las parcelas catastrales no dicen cuántas personas viven ahí; para población buscá capas censales. El GetCapabilities de cada servicio no publica licencia por capa: la licencia de cada capa concreta queda sin verificar.
