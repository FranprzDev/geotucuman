Cuatro herramientas

buscar_capas

Descubre qué capas existen por tema o palabra clave dentro del catálogo embebido.

describir_capa

Devuelve los campos reales de una capa. Obligatorio antes de consultarla.

consultar_capa

Trae features con filtros, paginación y bbox en EPSG:4326, reproyectado al CRS nativo de cada capa.

geocodificar

Convierte una dirección en coordenadas con la API Georef (gratis, sin key).

Cómo usarlo

De cero a tu agente en cuatro pasos

  1. Cloná e instalá
    git clone https://github.com/FranprzDev/geotucuman.git
cd geotucuman
npm install
  2. Compilá el servidor
    npm run build
    Genera dist/stdio.js y dist/http.js con xmcp.
  3. Conectalo a tu cliente MCP (ejemplo Claude Code):
    { "mcpServers": { "geotucuman": { "command": "node", "args": ["/ruta/geotucuman/dist/stdio.js"] } } }
  4. Listo: las cuatro herramientas quedan disponibles en tu agente.

Corre local por stdio. También compila un transporte HTTP (npm run start:http) pensado para hosting futuro: hoy no hay un servidor remoto público.

En una frase

No es un SIG. No aloja ni redistribuye datos. Solo te dice qué capa existe, quién la publica y dónde se consulta.

Límites claros

Lo que no hace, dicho sin vueltas

  • No es un SIG ni un visor: no arma mapas ni análisis; eso lo hacés vos con los datos.
  • No aloja ni redistribuye datasets: todas las consultas van a los servicios oficiales en vivo.
  • No fija licencias por capa: los GetCapabilities no las publican; los términos de cada organismo están en el índice de capas.
